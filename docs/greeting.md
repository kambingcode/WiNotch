# Launch greeting

Every time WiNotch starts, the notch comes alive for a few seconds, says hello, and goes back to
normal.

![The greeting's smiling eyes in the notch](screenshots/greeting.png)

## Sequence

Times count from the moment the box starts to drop. The greeting runs 9.15 s, plus 0.8 s for the
box to rise again.

| Time (s) | What happens |
|---|---|
| 0–0.5 | A black box as wide as the physical notch drops 44 pt, starting at the notch's exact size |
| 0.5–0.8 | Two closed eyes appear as thin glowing lines |
| 0.85–0.95 | The eyes open into upright ovals |
| 1.25–3.1 | The eyes glance 4 pt to the left, then to the right, then back to the center |
| 3.25–3.75 | A blink |
| 4–4.6 | The eyes turn into curves that smile upward |
| 4.6–5.6 | The smile holds for 1 s |
| 5.6–6.15 | The eyes fade, and the text appears in their place |
| 6.15–9.15 | The text holds for 3 s |
| 9.15–9.95 | The box rises back into the notch |

## How it works

| Part | Behavior |
|---|---|
| Timing and pose | `GreetingTimeline`, a pure function of time, so it's testable |
| Eye shape | `GreetingEye`, one shape that morphs from an oval into a curve |
| A song already playing | `NotchPresentation` holds it until the box has risen, then shows it like a new song |
| Hover | The notch can't open during the greeting |
| CPU | Redrawn every frame, but only while the greeting runs |
| Reduce motion | No eyes. Only the text fades in |
| Name | A field in the Notch tab. When it's empty, WiNotch uses the first name of the Mac account |
| Switch | "Sapaan saat aplikasi dibuka" (Greeting at launch), on by default |
| Sound | A "pop" when the eyes open and a warm chord as the text appears. The chord fades over about 3 s, the time the text stays up |
| Sound files | In `app/Resources`, generated by `scripts/make_greeting_sounds.py`. I synthesized them from scratch instead of imitating the Mac chime |
| When it stays quiet | When a song is playing, when reduce motion is on, or when the "Suara sapaan" (Greeting sound) switch is off |

## Decisions

1. The smile is two eyes curving upward.
2. The eyes give way to the text in a smooth transition, and the box keeps its size.
3. The text reads "Hello, Welcome [name]!" on one line.
4. It plays on every launch, including the automatic one after login.
5. I slowed the motion down and shrank the eyes to 16 × 23 pt.
6. The text holds for 3 s.
7. The eyes start closed, as a line, and open in 0.1 s.
8. The smile holds for 1 s.
9. The eyes glance left and right.
10. The sound is a pop and then a warm chord, muted while a song plays.
11. The box starts at the exact size of the physical notch, so nothing pops into view.
